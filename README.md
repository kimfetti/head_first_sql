## Who this Repository Is For

This repository is indended for readers following along with the book. It contains chapter scripts and supporting resources for learning about SQL. 

The `.sql` files allow readers to recreate the book databases to work through examples and practice SQL by examining the data on their own machines.

## Requirements

- MySQL (Version 8.0+) _preferred_

Get your own copy of [MySQL Community Edition](https://dev.mysql.com/downloads/mysql/) for free. Just select your OS and follow the installation instructions. See also Appendix II (B) in the book.

If you would like to use a different RDBMS (PostgreSQL, SQLite, etc.), note that you may need to occassionally update the book syntax.
